# Peter Kamau Portfolio

This version is intentionally self-contained: the CSS, JavaScript, and current placeholder graphics are embedded directly in `index.html`. That means it previews correctly as a single file and can also be deployed directly to GitHub Pages.

## Deploy
1. Create a repository named `PeterKamau24.github.io`.
2. Upload `index.html` to the repository root.
3. In GitHub Settings → Pages, deploy from the `main` branch/root.

## Replace later
- Replace the profile/intro placeholder with your real photo.
- Replace the five Personal Life placeholders.
- Add your final resume PDF and update the Resume card.
- Add the public Budget Buddy repository link when available.
